# Android Racing Game - HW2

A classic multi-lane racing game built for Android, featuring both manual button controls and tilt (sensor) based movement.

## 🎮 Features
* **5-Lane Road:** Extended gameplay area for more challenging maneuvering.
* **3 Play Modes:**
    * **Buttons (Slow):** Standard speed using on-screen left/right buttons.
    * **Buttons (Fast):** High-speed mode for an extra challenge.
    * **Sensor Mode:** Steer the car by physically tilting the device left or right (utilizing the device's Accelerometer).
* **Score & Economy:** Tracks travel distance (odometer) and allows players to collect coins along the way.
* **Immersive Experience:** Includes a crash sound effect (`MediaPlayer`) and device vibration upon collision.
* **High Scores & Google Maps:** A dedicated High Scores screen utilizing Fragments. It displays a list of the top 10 runs, and tapping a score updates a Google Map fragment to display the location where the record was achieved.
